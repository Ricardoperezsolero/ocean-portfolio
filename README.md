# GFW Portfolio Map

An interactive career and journalism portfolio built on a [Global Fishing Watch](https://globalfishingwatch.org/) ocean map.

## About

Before GFW tracked the ocean, I was reporting on it. This visualisation overlays a decade of field reporting across Southeast Asia, Europe and Latin America onto GFW's fishing activity data — showing the geographic overlap between my journalism career and the ocean issues GFW monitors.

## Features

- Interactive map with zoom and pan
- Career location pins with role descriptions and dates
- Portfolio story pins linked to published work and video
- Tag filter to explore by topic (Journalism, Migration, Ocean Governance, etc.)
- Animated GFW 2030 Goals marker

## Built with

- Vanilla HTML, CSS and JavaScript — no frameworks or dependencies
- Global Fishing Watch map imagery
- Hosted on Cloudflare Pages
